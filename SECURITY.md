# Security policy

**The contact address for reporting vulnerabilities (and for takedown requests) is
not set yet.** Until it is, please do not open a public issue describing a
vulnerability or a malicious plugin. Once the repository is public, this file will
name a reporting address and a response target.

Note that the registry cannot yet revoke a published version for installed copies:
a takedown only stops new installs. The signing private key never belongs in this
repository; `REGISTRY_SIGNING_KEY` is a repository secret that has not been created yet.
